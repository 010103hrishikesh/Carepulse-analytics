CarePulse Analytics

Automated Healthcare Readmission Prediction & Cloud Analytics Pipeline

Project Overview

CarePulse Analytics is an end-to-end healthcare analytics and machine learning project designed to predict patient readmission risk using historical hospital data. The project combines data engineering, cloud analytics, machine learning, and business intelligence to create a scalable healthcare analytics solution.
